## 🏪 ¿Qué es este giro?

Barra de bebidas frías personalizables: el cliente elige base (té, leche o fruta), sabor, toppings (perlas de tapioca, popping boba, jelly) y tamaño.

## 🎯 ¿A quién le vendes?

Adolescentes y jóvenes que buscan bebidas diferentes y "instagrameables".
